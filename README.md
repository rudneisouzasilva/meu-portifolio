# Portfólio de Rudnei Souza Silva

**No ar:** https://rudnei-souza.vercel.app

Site pessoal com meus projetos, trajetória e contato. Infraestrutura de TI, desenvolvimento web e IA aplicada.

É uma página estática (HTML e CSS em um único arquivo, `index.html`), sem build e sem dependências. As fontes vêm do Google Fonts.

## Ver localmente

Abra o `index.html` no navegador.

## Publicação

Hospedado na Vercel, ligado a este repositório: cada commit na `main` atualiza o site automaticamente.

## Projetos apresentados

- [LumenzIA](https://github.com/rudneisouzasilva/lumenzIA): assistente de IA no WhatsApp e CRM para clínicas de estética
- [Expedito](https://github.com/expedito-app/expedito): controle das tarefas externas da expedição portuária
- [URA Clara](https://github.com/rudneisouzasilva/ura-clara-whatsapp): campeão do Hacka PagBank 2026
- [Lista de tarefas](https://github.com/rudneisouzasilva/todo-app-angular-node), [SIGEM](https://github.com/rudneisouzasilva/sigem-gestao-equipamentos), [Envia chat relay](https://github.com/rudneisouzasilva/envia-chat-relay) e [Cadastro de disciplinas](https://github.com/rudneisouzasilva/cadastro-disciplinas-winforms)
